# JTBD 与第一期边界

## 工作

**When** 我想在公众号 / 知乎 / 小红书有个号，但不会写、没运营过，手里常有现场照片或短视频，**I want** 把主题和素材分析清楚、排进能贴进各站后台的成稿，**so I can** 自己点发表，图文对得上真事。

- 功能：文字锚点 + 素材分析 + 长文插图 + 笔记多图；**复制并打开后台**。
- 不做：代发、过检测、200 场景墙、C 端配模型、MCP 市场。

## C 端步骤

注册（邮箱密码）→ 订阅或体验额度 → 选题（白话三选 + 一句话 + ≥2 锚点）→ 可选上传图/短视频并确认分析卡片 → 生成成稿（大纲 / 母稿 / 适配 / 检查闭锁一次跑完）→ 复制并打开后台。复制页展示声明说明，不勾选。

订阅过期或额度用尽：**只读已有稿，不能「按这个写」**。

## 成功标准

不会写的人能走完主路径；运营能禁用账号；界面无「过检测」「一键发表」；无锚点不能生成。
