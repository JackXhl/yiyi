# C 端 UI

对标微信公众号后台 / 掘金创作后台 / 小红书创作中心。不是 SaaS 仪表盘，不是 AI 聊天页。

## Token

- 画布 `#FFFFFF`，页底 `#F5F5F5`，分割 1px `#E7E7E7`
- 主色 `#07C160`，链接 `#1E80FF`，正文 `#191919`，次要 `#576B95`
- 圆角 4–6px；顶栏 56px；左栏 200px
- 系统黑体；中文状态（草稿，不写 draft）
- hover/focus 150–200ms

标准控件 TDesign `t-*`。只自绘步骤条、三档预览、双栏编辑。

## 禁止

紫渐变、KPI 墙、Chat 对话墙、emoji 图标、按钮「发布 / 同步上线」、TDesign Starter / Chat 整页套用。

主按钮文案：写一篇 / 写第一篇 / 按这个写 / **复制并打开后台**。
