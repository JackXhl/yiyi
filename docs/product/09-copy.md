# 对外文案词表

界面唯一用词。C 端创作者台：专业、好懂。控制台：正规，每项有说明。禁止口语：抽检、能力槽、按这个写、两个都要、签发、吊销、槽、轴。

## 品牌与入口

- 控制台品牌：一意控制台
- 控制台登录页：控制台登录
- C 端品牌：一意
- C 端侧栏：作品 / 创作 / 账户
- C 端主按钮：新建作品 / 生成成稿 / 免费开始
- 空态：暂无作品
- 作品筛选：全部 / 草稿 / 已成稿
- 套餐标记：当前套餐
- 事实字段对外称：事实依据（代码仍用 `anchors`）

## 控制台菜单

- 工作台：数据概览
- 业务运营：用户管理、内容审核
- 订阅商业：套餐管理、订单管理
- 内容引擎：生成任务、内容类目、模型配置、提示词模板、写作技能、风格预设、开放接口
- 系统管理：角色权限、操作日志

## C 端芯片

- form.long 公众号长文
- form.note 小红书图文
- form.both 长文与笔记
- intent.story 经历叙述
- intent.howto 方法教程
- intent.opinion 观点评论
- intent.promo 商品推荐（advertising）

步骤条：填写（选题 / 素材）／成稿（大纲 / 正文 / 渠道适配）／复制（合规检查 / 复制发布）。内部仍是这七个节点。

## 闸门

- 请填写至少 4 个字的作品主题
- 请选择至少一个内容类目
- 请至少填写两条已确认的事实依据
- 订阅已到期，仅可查看已有作品
- 本月生成额度已用完

## 控制台字段说明（短标签 / 引导）

- 登录邮箱：运营账号邮箱，不是 C 端用户邮箱。
- 登录密码：至少 8 位。连续失败会短暂锁定。
- 用户邮箱：C 端注册邮箱，可模糊搜索。
- 套餐：用户当前订阅方案。修改后立即生效，不自动扣款。
- 停用用户：停用后无法登录 C 端，已有作品仍保留。
- 作品状态：草稿 / 生成中 / 已成稿 / 失败。
- 套餐价格：界面显示元，系统按分存储。
- 任务状态：排队中 / 进行中 / 成功 / 失败。仅失败可重试。
- 类目内部编号：系统编号，请勿改。中文名称才是 C 端文案。
- 能力类型：长文生成 / 大纲生成 / 视觉理解。
- 接口地址：百炼填 `https://dashscope.aliyuncs.com/compatible-mode/v1`，不要加 `/chat/completions`。
- API 密钥：只显示「已保存」。留空表示不修改。
- 提示词节点：大纲 / 正文。禁止加入绕过检测的要求。
- 访问令牌：明文只出现一次，关闭后无法再看。
