# Design System: 一意创作台

对标 **小红书创作中心网页版** 的结构与密度，不是抄小红书品牌红。一意仍然发公众号长文 + 笔记，主色保持微信绿。Agent 实现 C 端时只读本文件；文案仍以 [09-copy.md](09-copy.md) 为准。

## 1. Visual Theme & Atmosphere

浅灰工作室，不是 SaaS 仪表盘，不是 AI 聊天页，不是公众号后台那种「左栏纯文字链 + 中间表单」。

气质来自小红书创作中心：`#F5F5F5` 画布、白卡片浮起、右上角主按钮、写稿时 **右侧永远有一台 3:4 手机预览**。登录页不是灰底小卡片，而是 **左大预览台、右登录纸**。

- Density: Daily App Balanced（5/10）。作品用封面格，不用表格。
- Variance: Offset（5/10）。登录与写稿强制左右分栏；作品列表是 3:4 网格。
- Motion: Static Restrained（3/10）。只做 hover / active 180ms。禁止滚动视差、 marquee、紫光。

签名元素（全站只此一件要被记住）：**双机位预览台**。右栏固定一台圆角手机（笔记 3:4）+ 必要时一张公众号纸（677 逻辑宽缩放到约 320px）。封面、主题、图序、成稿都先出现在这台设备上。

## 2. Color Palette & Roles

- **Studio Gray** `#F5F5F5` — 页底、登录左栏、写稿右栏底
- **Paper** `#FFFFFF` — 顶栏、侧栏、卡片、表单纸、手机屏幕
- **Ink** `#191919` — 主文字
- **Caption** `#5C5C5C` — 次要文字、时间、空态。白底正文对比须 ≥4.5:1，不再用 `#8A8A8A`。链接用墨色加下划线，品牌绿只做实心按钮和激活底，不当链字色
- **Hairline** `#EBEBEB` — 1px 分割
- **WeChat Leaf** `#07C160` — 唯一强调色：主按钮填充、焦点环。导航与步骤当前项用 Leaf Soft 底 + 深绿字，不当链字色。禁止改成小红书红 `#FF2442`
- **Leaf Soft** `#E8F8EF` — 导航激活底、芯片选中
- **Danger** `#FA5151` — 错误与高风险，不用于装饰

禁止：纯黑 `#000000`、紫渐变、霓虹外发光、暖米色纸（`#F4F1EA` 一类 AI 默认）。

## 3. Typography Rules

- **Display / 标题：** PingFang SC, "Noto Sans SC", "Microsoft YaHei", sans-serif。字重 600。登录主标题 28px / 行高 1.25；页内标题 20px。
- **Body：** 同一家族 400，16px，行高 1.6。预览正文最大宽度 65ch。
- **Meta：** 13px Caption 色。状态用中文（草稿 / 生成中 / 已成稿），禁止 `draft`。
- **Banned：** Inter、衬线标题、全大写 eyebrow、装饰性中间点堆砌。

## 4. Component Stylings

**顶栏** 64px 白底，底边 Hairline。左：字标「一意」16px/600。右：主按钮「新建作品」。不要 KPI、不要头像墙。

**侧栏** 200px 白底。每项：图标井 32px + 中文。激活：Leaf Soft 底 + Leaf 字，左侧 3px Leaf 条。hover 180ms。三项固定：作品 / 创作 / 账户。

**主按钮** TDesign primary，映射 `--td-brand-color` = Leaf。圆角 8px。active 时 `translateY(1px)`。禁止描边发光。次按钮 outline / 白底。文案：新建作品、生成成稿、免费开始、复制并打开后台。禁止「发布」「同步上线」。

**卡片** 圆角 12px，Paper 底，Hairline 边，阴影 `0 8px 28px rgba(25,25,25,0.06)`。只在作品格、套餐、预览手机需要抬升时使用。高密度清单用分割线。

**作品卡** 小红书笔记卡：封面 3:4，圆角 12px 顶部裁切；下方标题两行截断 + 状态 + 时间。网格 `repeat(auto-fill, minmax(180px, 220px))`，间距 16px。卡宽封顶，少稿时不撑满整行。空态居中：一句「暂无作品」+ 主按钮。

**输入** 标签在上，辅助在下，错误贴字段。圆角 8px，焦点环 Leaf。禁止用 placeholder 当标签。

**芯片** 圆角 8px，默认白底 Hairline；选中 Leaf Soft + Leaf 字。

**步骤条** 三态（取材 / 成稿 / 取稿），用 TDesign Steps：圆点连线、已完成 / 进行中 / 未到。成稿内可切大纲 / 正文 / 渠道适配。取材与取稿不再分子步。禁止胶囊页签当主路径。

**手机预览** 宽 280px，高按 3:4，外框 Ink 8% 透明度，圆角 28px，内屏 Paper 圆角 20px。顶部细状态条（时间点即可，不要天气）。封面铺满上半，标题 16px/600，正文 13px Caption。

**公众号纸** 宽 320px（代表 677 逻辑宽），白底，内边距 16px，圆角 4px（公众号真实观感偏直角，故意与笔记卡区分）。

**加载** 与卡片同尺寸的骨架闪光，禁止居中大转圈作为主状态。

**空状态** 构图：预览台轮廓 + 一句话 + 一个主按钮。

## 5. Layout Principles

登录 / 注册 / 落地：

```
+---------------------------+------------------+
|  Studio Gray              |  Paper 480px     |
|  双机位预览（样例成稿）     |  字标 + 表单      |
|  左对齐，垂直居中           |  垂直居中         |
+---------------------------+------------------+
```

内部壳：

```
+--------------------------------------------------+
| 64 顶栏  一意                     [新建作品]      |
+--------+-----------------------------------------+
| 200    |  Studio Gray                            |
| 导航   |  作品：封面格                            |
|        |  写稿：左编辑 1fr + 右预览 360          |
|        |  账户：套餐卡 + 订单行                   |
+--------+-----------------------------------------+
```

写稿工作室：

```
+-- 三态：取材 — 成稿 — 取稿 -----------------------+
| 取材：选题+素材同一页；成稿：大纲/正文/适配；取稿：声明+底栏复制 |
+------------------------------+-------------------+
| 编辑纸（白卡片）               | 预览台（粘性）     |
| 芯片 / 上传 / 纯文本           | 一机位 + 笔记/公众号 |
+------------------------------+-------------------+
| 底栏：生成成稿 / 再生成成稿 / 复制并打开后台         |
+--------------------------------------------------+
```

取材确认后点「生成成稿」，四步闭锁自动跑，进度显示在编辑纸顶。生成中不能改、不能回取材。取稿页只展示声明说明，不勾选。

- 写稿主区 `min-height: calc(100dvh - 64px)`，右栏 `position: sticky; top: 80px`。
- `768–1023px`：收起侧栏，三项导航改到顶栏。
- `<768px`：壳隐藏，只显示「请使用电脑端完成创作」。
- 最大内容宽：作品格 1200px；写稿不设 1120 上限，让预览台靠右。
- 禁止三列等大功能卡、禁止把写操作塞进表格单元格。

## 6. Motion & Interaction

- Hover / focus：180ms `ease`。只变动背景、边框、transform。
- 主按钮 `:active { transform: translateY(1px); }`
- `prefers-reduced-motion: reduce` 时 duration 0。
- 禁止无限循环、滚动劫持、自定义鼠标。

## 7. Anti-Patterns (Banned)

- 灰底居中小登录卡（旧实现）
- 作品列表做成文件行（旧 `draft-row`）
- 写稿页没有右侧设备预览
- 小红书红当主色、微信绿当点缀混用
- emoji 当图标、紫渐变、Chat 对话墙、KPI 数字墙
- 按钮文案「发布 / 同步上线 / 按这个写」
- Inter、衬线标题、纯黑、霓虹阴影
- 假仪表盘 HTML 当 Hero（预览必须是本产品的手机/公号组件）

## 8. Screen recipes

**登录** 左：两台设备叠放，手机展示示例笔记封面与标题「店里那根灯管」，公号纸展示两行正文。右：标题「登录一意」，副文「使用邮箱登录创作台。成稿由你本人粘贴到各平台后台。」邮箱、密码、登录、去注册。

**注册** 同一分栏。主按钮「注册」。副文保留体验额度说明。

**落地** 同一左预览。右：一意、产品一句话、免费开始、登录链接、套餐行（名称 / 价格元 / 月篇数）。

**作品** 页头一行「作品」+ 状态芯片（全部 / 草稿 / 已成稿）。加载用同尺寸骨架。无封面用淡底纹理，不用单字。无数据空态。

**创作** 按第 5 节工作室。侧栏「创作」打开最近一篇，不新建空稿；新建只走顶栏「新建作品」。选题步类目默认收起「更多」。正文是纸面编辑：空行分段，不露标签，粘贴去标签；右侧公众号预览同步。右栏始终一台设备，用笔记/公众号芯片切换。登录左栏仍可叠放双机位作为签名。

**账户** 一张配额卡（邮箱、套餐、剩余篇数、到期）+ 套餐卡列表（当前套餐有标记）+ 订单行。退出为次按钮。
