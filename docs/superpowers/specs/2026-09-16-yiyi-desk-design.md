# C 端逐屏施工图

气质：微信公众号后台。白底、绿主按钮、稿在中间。

1. 登录/注册：白卡片、邮箱密码、绿登录。无三方按钮墙。
2. 稿件空态：「还没有稿」+ 写第一篇。有稿则列表（封面、标题、草稿/生成中/已成稿、时间）。
3. 写一篇步骤条：选题 / 素材 / 大纲 / 正文 / 适配 / 检查 / 复制。
4. 选题：三道白话芯片 + 一句话 + 两条锚点。缺锚点时主按钮灰：「还差一条你亲历过的事」。
5. 素材：1px 虚线上传，分析卡片需点「用这条当锚点」。
6. 大纲/正文：左编辑右预览（公众号宽 / 笔记宽）。
7. 检查：清单对钩；高风险未勾不能复制。主按钮「复制并打开后台」。
8. 账号：到期日、剩余篇数、订单表。无 KPI 卡。

<768：提示请用电脑写稿。
